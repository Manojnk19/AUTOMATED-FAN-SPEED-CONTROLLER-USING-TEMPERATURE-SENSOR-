# Automated Fan Speed Controller Using IR Sensor and Temperature Sensor

## Project Overview
This project is an automated fan speed controller developed using Arduino UNO, DHT11 temperature sensor, and IR sensor. 
The system automatically adjusts the fan speed according to room temperature and detects human presence using an IR sensor.

## Features
- Automatic fan ON/OFF control
- Temperature-based fan speed control
- Motion detection using IR sensor
- PWM based speed regulation
- Energy efficient operation

## Components Used
- Arduino UNO
- DHT11 Temperature Sensor
- IR Sensor
- L298N Motor Driver
- DC Fan
- LCD Display
- Breadboard
- Jumper Wires

## Software Used
- Arduino IDE
- Embedded C Programming

## Working Principle
1. IR sensor detects human presence.
2. DHT11 sensor reads room temperature.
3. Arduino processes sensor values.
4. Fan speed changes automatically using PWM.
5. Fan turns OFF when no motion is detected.
